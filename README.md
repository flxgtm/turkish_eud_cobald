# Enhanced Universal Dependencies для турецкого языка

Этот репозиторий содержит датасет, результаты экспериментов и код, использованные в практической части магистерской диссертации, посвящённой Enhanced Universal Dependencies для турецкого языка.

## Описание проекта

В работе предлагается набор правил расширенной UD-разметки для турецкого языка и проверяется возможность автоматического восстановления enhanced-зависимостей с помощью модели CoBaLDParser.

Основное внимание уделяется конструкциям, в которых часть аргументных отношений не представлена отдельными зависимостями в базовом UD-дереве:

* конструкции с контролем (`xcomp`);
* конвербные конструкции (`advcl`);
* сочинительные конструкции (`conj`);
* относительные конструкции (`acl`).

## Данные

Данные представлены в двух форматах:

* `data/jsonl/` — JSONL-сплиты, использованные для обучения и оценки модели;
* `data/conllu/turkish_eud.conllu` — полный CoNLL-U-файл с заполненной колонкой `DEPS`.

Основные файлы данных:

* `data/jsonl/train.jsonl`
* `data/jsonl/dev.jsonl`
* `data/jsonl/test.jsonl`
* `data/conllu/turkish_eud.conllu`

Датасет основан на UD Turkish IMST и содержит представление полного enhanced-графа в поле `deps` / колонке `DEPS`.

## Эксперименты

Качество восстановления enhanced-графа оценивалось по полному совпадению троек:

`head -- dependent -- relation`

Основные результаты на тестовой выборке:

| Модель             | Precision | Recall |     F1 | Jaccard |
| ------------------ | --------: | -----: | -----: | ------: |
| Baseline           |    0.4102 | 0.4554 | 0.4316 |  0.2752 |
| Pos_weight = 10    |    0.3916 | 0.4983 | 0.4386 |  0.2809 |
| Russian pretrained |    0.4159 | 0.4027 | 0.4092 |  0.2572 |
| Frozen encoder     |    0.3072 | 0.3214 | 0.3141 |  0.1863 |
| Fresh EUD head     |    0.1575 | 0.3441 | 0.2161 |  0.1211 |
| Two-stage training |    0.5623 | 0.5476 | 0.5548 |  0.3839 |

Сохранённые результаты экспериментов находятся в папке `experiments/`.

## Код

Основной код для обучения и оценки находится в папке `code/CobaldParser/`.

Ключевые скрипты:

* `code/CobaldParser/train_eud.py` — обучение модели на EUD-датасете;
* `code/CobaldParser/evaluate_eud.py` — оценка модели на dev- или test-выборке.

Пример запуска оценки:

```bash
python code/CobaldParser/evaluate_eud.py --model-dir models/eud_baseline --split test
```

Большие файлы с весами моделей не включены в репозиторий, поэтому для запуска оценки необходимо предварительно обучить модель или указать путь к уже сохранённой модели.
